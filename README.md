# IoT Smart Plug

IoT-based smart plug project for controlling electronic devices remotely.

## Features
- Device control system
- Smart plug automation
- Electronic device monitoring
- Real-time control

## Components
- Arduino / ESP
- Relay Module
- Smart Plug
- Jumper Wires

## Technologies
- Arduino C++
- IoT System

## Functions
- Turn devices ON/OFF
- Monitor connected devices
- Smart automation system
